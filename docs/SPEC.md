# Спецификация

## Задание (кратко)
Контур 1 — оценка:
1. Редактор чек-листа: добавлять/менять критерии, формулировки, вес, тип ответа,
   доступность N/A, шкалу. Сохранение версий.
2. Оценка диалога: загрузка транскрипта, выбор чек-листа, запуск. RU, KZ, EN.
3. Результат: по каждому критерию — ответ, баллы, вес, объяснение, реплика-
   доказательство. Если действие пропущено — проверенный участок разговора.
   При N/A — причина. Итог и итоги секций.
Контур 2 — работа с результатом:
4. Карточка: из списка к транскрипту и результату; ссылка в обосновании ведёт
   к нужному сообщению; для звонка — перемотка плеера.
5. Апелляция: выбрать критерий, комментарий, сохранить.
6. Решение проверяющего: подтвердить или изменить с причиной; пересчёт итога;
   видны исходная оценка, решение и финальный результат.
Плюс: пакетная оценка набора по group_id (контрольный набор из 10 диалогов выдают
на 23-м часу), замена критерия через UI и повторное применение.

## Расчёт баллов
- Да = полный вес, Нет = 0.
- Шкала: points = value / max_step * weight.
- N/A исключается; total = sum(points) / sum(weights применимых) * 100.
- Округление итога до 2 знаков. Нет применимых критериев с весом → total = null.
- Критерий типа flag (грубые ошибки) баллов не даёт, отмечается отдельно.
- Итог секции считается так же, но только по критериям секции.
- В этом задании порог первой реакции 3 минуты, теги и вложения в оценку не входят.
- Пример: 01=Да, 02=N/A, 03=N/A, 04=15, 05=Да, 06=7, 07=Да →
  (10+15+15+10.5+5)/65*100 = 85.38

## Требования к доказательствам
- Действие выполнено → номер реплики + короткая цитата.
- Действие пропущено → диапазон проверенных реплик (где оно ожидалось).
- N/A → какое условие неприменимости выполнено.
