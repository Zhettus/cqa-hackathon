## 1. Как запускать

```
pip install -r requirements.txt              # или .venv (Python 3.12)
cp .env.example .env                          # LLM_API_KEY=… ; VOTES, NORMALIZE_CALLS — см. §5
.venv/bin/python -m pytest -q                 # 237 passed, 1 skipped
.venv/bin/uvicorn backend.main:app --reload   # http://localhost:8000 → /ui/, /docs, /api/meta
.venv/bin/python -m eval.run --gold eval/gold_tune.json --votes 3          # ≈ $17, 11 мин
.venv/bin/python -m eval.run --gold eval/edge_cases.json --votes 3         # ≈ $4, 2 мин
.venv/bin/python -m eval.run --gold eval/gold_tune.json --channel "voice call" --normalize   # звонки с корректором
.venv/bin/python -m eval.run --gold … --db data/exp.db --version 2         # эксперимент на отдельной БД без кэша
.venv/bin/python -m eval.compare eval/reports/A.json eval/reports/B.json   # дельта по критериям
python scripts/build_reference_version.py --criterion c04 [--db data/cqa.db]   # версия чек-листа со справочником
python scripts/rehearsal.py --base http://localhost:8000 --group DEV --limit 10  # репетиция этапа 7
```

- Кэш оценок: ключ (диалог, версия чек-листа, версия промпта, модель, effort, голоса). Версия промпта =
  `PROMPT_SCHEME` + хеш `backend/prompt.py` и `docs/rules.md` (+ версия корректора для звонков с
  нормализацией). Любая правка этих файлов → полный платный прогон. `GET /api/meta` показывает текущие
  версии промпта и чек-листов.
- Эталон: `eval/gold_tune.json` и `eval/gold_holdout.json` — источник правды; `eval/gold_draft.json` — архив.
  Поле `accept` в записи — допустимые альтернативы ответу. Holdout не открывать и не запускать.
- Стоимость ≈ $0.10 на диалог за голос; нормализация звонка ≈ $0.10 (один раз, кэш).
