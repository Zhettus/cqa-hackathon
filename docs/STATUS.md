## 1. Как запускать

```
pip install -r requirements.txt              # или .venv (Python 3.12)
cp .env.example .env                          # LLM_API_KEY=… (или ANTHROPIC_API_KEY / профиль ant auth login)
.venv/bin/python -m pytest -q                 # 220 passed, 1 skipped
.venv/bin/uvicorn backend.main:app --reload   # http://localhost:8000 → /ui/, /docs, /api/health
.venv/bin/python -m eval.run --gold eval/gold_tune.json --votes 1     # полный прогон ≈ $6.2, 4 мин
.venv/bin/python -m eval.run --gold eval/edge_cases.json --votes 1    # ≈ $1.4, 1 мин
.venv/bin/python -m eval.run --gold eval/gold_tune.json --ids p1-ru-003 --no-cache   # один диалог
.venv/bin/python -m eval.compare eval/reports/A.json eval/reports/B.json             # дельта по критериям
python scripts/download_audio.py              # mp3 звонков → data/audio/ (подписанные ссылки живут ~1 ч)
```

- Кэш оценок: ключ (диалог, версия чек-листа, версия промпта, модель, effort, голоса); повторный `eval.run`
  без изменений промпта/rules.md не вызывает модель. Версия промпта = `PROMPT_SCHEME` + хеш `prompt.py` и
  `docs/rules.md` — любая правка этих файлов означает полный платный прогон.
- Стоимость ≈ $0.10 на диалог (1 голос; ~90 % входа читается из кэша промпта). `--votes 3` ≈ ×3.
- Ollama/vLLM: `LLM_PROVIDER=openai`, `LLM_BASE_URL=http://localhost:11434/v1`, `LLM_MODEL=…`.
- `eval/gold_holdout.json` не открывать и не запускать — только человек, в самом конце.
