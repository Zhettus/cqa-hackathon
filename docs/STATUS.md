## 1. Как запускать

```
pip install -r requirements.txt              # или .venv (Python 3.12)
cp .env.example .env                          # LLM_API_KEY=… (или ANTHROPIC_API_KEY / профиль ant auth login)
.venv/bin/python -m pytest -q                 # 232 passed, 1 skipped
.venv/bin/uvicorn backend.main:app --reload   # http://localhost:8000 → /ui/, /docs, /api/health
.venv/bin/python -m eval.run --gold eval/gold_tune.json --votes 1     # полный прогон ≈ $6, 4 мин
.venv/bin/python -m eval.run --gold eval/edge_cases.json --votes 1    # ≈ $1.3, 1 мин
.venv/bin/python -m eval.run --gold eval/gold_tune.json --channel "voice call" --normalize   # звонки с корректором ASR
.venv/bin/python -m eval.run --gold eval/gold_tune.json --ids p1-ru-003 --no-cache          # один диалог без кэша
.venv/bin/python -m eval.compare eval/reports/A.json eval/reports/B.json                    # дельта по критериям
python scripts/download_audio.py              # mp3 звонков → data/audio/ (подписанные ссылки живут ~1 ч)
```

- Кэш оценок: ключ (диалог, версия чек-листа, версия промпта, модель, effort, голоса); для звонков с
  нормализацией версия промпта получает суффикс `+n1-…` (версия корректора). Любая правка
  `backend/prompt.py` или `docs/rules.md` меняет версию промпта → полный платный прогон.
- Стоимость ≈ $0.10 на диалог (1 голос, ~90 % входа из кэша промпта); нормализация звонка ≈ $0.10–0.15
  дополнительно, один раз на диалог (кэш в `normalizations`). `--votes 3` ≈ ×3.
- Эталон: поле `accept` в записи (`{"c04": [0, 10]}`) — допустимые альтернативы ответу; итог для MAE
  пересчитывается под принятый ответ. Диалог без оценки при наличии эталона — ошибка по всем критериям.
- Ollama/vLLM: `LLM_PROVIDER=openai`, `LLM_BASE_URL=http://localhost:11434/v1`, `LLM_MODEL=…`.
- `eval/gold_holdout.json` не открывать и не запускать — только человек, в самом конце.

## 4. Нормализация звонков (этап 5): до / после

и оператора — `text_clean` и `asr_uncertain`; оригинал не меняется; кэш по хешу транскрипта. Включается
`NORMALIZE_CALLS=1` или `--normalize`; по умолчанию выключено. Промпт оценки получает строку `clean:` под
репликой, флаг `ASR_неуверенно` и правило «не ставить в вину формулировки из неуверенных фрагментов».
