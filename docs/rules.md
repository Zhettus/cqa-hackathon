# Трактовки правил чек-листа

R1. Приветствие и действия бота оператору не засчитываются. Оператор начинается
    с первой его реплики после события эскалации («Агент присоединился» в звонках).

R2. c01: «Да» — в первой реплике оператора есть приветствие и имя, на языке клиента.
    «меня зовут [Имя скрыто]» = представился. «Привет»/«Сәлем» без имени,
    отсутствие приветствия, приветствие не на языке клиента → «Нет».
    Повторный звонок оператора без приветствия → «Нет».

R3. c02: N/A — если к моменту подключения оператора данных хватало (включая
    сообщения клиента боту и до подключения). «Да» — оператор уточнил недостающее.
    «Нет» — переспросил уже сказанное или ответил без нужного уточнения.

R4. c03: «Да» — подтверждение (системное событие или словесное в звонке) ДО
    раскрытия данных или защищённого действия. Раскрытие до подтверждения → «Нет».
    Данные третьего лица → «Нет». Оператор корректно запросил идентификацию,
    клиент отказался, ничего не раскрыто → N/A .

R5. c04: второй существенный вопрос проигнорирован → 10; не раскрыта
    второстепенная деталь → 15; первый совет ошибочен, но итоговый ответ верный →
    оценивается итоговый ответ.

R6. c05: клиент выразил недовольство, а реакции нет → «Нет». Оскорбление → «Нет».
    Если недовольства не было — достаточно вежливости.

R7. c06: первая реакция > settings.first_response_threshold_s или пауза без
    предупреждения → не выше 7. Клиент переспрашивает из-за паузы или формулировок → 4.
    Объявленное ожидание или удержание — не нарушение. Ошибки распознавания речи —
    не ошибки оператора.

R8. c07: прощание после того, как клиент подтвердил решение, → «Да» (подтвердить).
    Итог или следующий шаг плюс прощание → «Да». Оператор закрыл чат без
    прощания или ответил без прощания («Жақсы.») → «Нет». Обрыв связи, уход
    клиента, клиент положил трубку сразу после благодарности → N/A.

R9. c08: перевод денег оператору лично; личный номер для платной консультации;
    оскорбление; раскрытие данных счёта без идентификации;
    данные третьего лица.

R10. Звонки: реплики на удержании, в консультации с коллегой, в IVR и после
     «Клиент завершил разговор» не оцениваются как общение с клиентом.

R11. Нет реплик оператора → not_evaluable.
