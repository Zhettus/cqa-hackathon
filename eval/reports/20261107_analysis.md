## Предложения (ОБЩИЕ, не применены)

**П1. Промпт: каждый недостаток — ровно в одном критерии.** В блок критерия добавлять из конфига чек-листа
список остальных критериев (название + описание) и правило: «Не снижай этот критерий за недостаток,
который оценивает другой критерий из списка». Код не знает id критериев, всё берётся из чек-листа.
Закрывает группу 1 (до 16 расхождений).

**П2. docs/rules.md, R7 (c06):** «c06 оценивает форму ведения диалога: ясность, связность, порядок ответов,
предупреждение об ожидании. Ответ не по теме или противоречащие друг другу реплики — один заметный сбой (7).
Ступень 4 — только если клиент переспрашивает, потому что не понял сформулированное оператором. Неполный
или проигнорированный ответ по существу — c04, переспрос уже сказанного клиентом — c02, тон — c05:
c06 за них не снижается».

**П3. docs/rules.md, R5 (c04):** «Второстепенная деталь — то, о чём клиент спросил или без чего не сможет
выполнить данный совет. Информация, о которой клиент не спрашивал, на балл не влияет. Подтверждение клиента
„нашёл/понял/получилось“ — довод за 20». Плюс решение по edge-ru-007: ошибочный ответ на второй существенный
вопрос → 10 (как неотвеченный) или 0 (ключевая рекомендация ошибочна).

**П4. docs/rules.md, R6 (c05):** «Недовольство — явное выражение раздражения, жалоба на сервис или оператора
(„надоело“, „это грубо“, „со мной так говорить не надо“). Нейтральное „я уже писал“ — не недовольство.
Неполнота ответа оценивается в c04, а не в c05».

**П5. docs/rules.md, R3 (c02):** «Уточнение более точной детали („вчера“ → точное время, „доллары“ → сумма) —
не переспрос».

**П6. docs/rules.md, R4 (c03):** «Нет — только если оператор раскрыл реальные данные счёта или выполнил/пообещал
защищённое действие без подтверждения. Догадка без обращения к данным счёта — не раскрытие (N/A, если иначе
идентификация не требовалась)». И решение по p4-ru-005 (это ошибка эталона или третье лицо рядом допустимо?).

**П7. docs/rules.md, R8 (c07):** решить для p1-ru-029: прощание после жалобы клиента без реакции — «Да» по R8
или «Нет»? Если «Нет» — добавить в R8: «прощание сразу после жалобы клиента, оставленной без ответа, — Нет».
